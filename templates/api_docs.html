Developer Reference

REST API Documentation

All endpoints are served from this app's base URL. Responses are JSON unless noted. No authentication is required for this academic demo.

⇩ Download Postman Collection ⇩ Download Sample Batch CSV
POST/predict

Scores a single applicant and returns a risk verdict, confidence score, CIBIL score, recommendation, ranked explanation, and a computed loan offer (interest rate, EMI, totals).

Request body (JSON)
{
  "applicant_name": "Priya Sharma", "age": 32, "gender": "Female",
  "employment_status": "Salaried", "annual_income": 650000, "co_applicant_income": 0,
  "loan_amount": 150000, "loan_duration": 36, "credit_history": "Good",
  "existing_loans": 1, "debt_to_income_ratio": 22, "loan_purpose": "Home",
  "cibil_score": 780, "pan_verified": "Yes", "collateral_provided": "Yes",
  "bank_relationship_years": 4, "residential_status": "Owned"
}
Response
{
  "risk": "Low Risk",
  "probability": 93.47,
  "message": "Eligible for Loan Approval",
  "applicant_name": "Priya Sharma",
  "cibil_score": 780,
  "loan_offer": {
    "eligible": true, "interest_rate_pct": 9.0, "monthly_emi": 4769.96,
    "total_interest": 21718.56, "total_payable": 171718.56
  },
  "explanation": [
    {"feature": "Annual Income", "impact": 14.665, "direction": "supports"},
    {"feature": "CIBIL Score", "impact": 1.102, "direction": "supports"}
  ]
}
cURL
curl -X POST https://YOUR_HOST/predict \
  -H "Content-Type: application/json" \
  -d '{"applicant_name":"Priya Sharma","age":32,"cibil_score":780,"...":"..."}'
GET/sample-applicant

Returns one random real applicant row from the training dataset, formatted to match the /predict request shape — powers the "Load Sample Applicant" button on the Assessment page.

POST/batch-predict

Upload a CSV of applicants (multipart/form-data, field name file) and receive a prediction for every row. Max 500 rows per request. Required columns include the new banking fields (cibil_score, pan_verified, collateral_provided, co_applicant_income, bank_relationship_years, residential_status) alongside the original fields.

cURL
curl -X POST https://YOUR_HOST/batch-predict -F "file=@applicants.csv"
GET/batch-predict/sample

Downloads a sample CSV template with the exact columns expected by /batch-predict.

POST/export-pdf

Generates a downloadable PDF report for one prediction, including the CIBIL score and top contributing factors.

GET/metrics

Returns saved evaluation metrics for all 3 trained supervised models. Powers the Model Performance dashboard.

GET/dashboard-data

Returns aggregate analytics across every prediction logged by this server. Powers the Analytics dashboard.

GET/segments-data

Returns the K-Means customer segmentation report: per-segment financial profile, persona label, PCA 2D coordinates, and Silhouette Score. Powers the Segments dashboard.

GET/anomalies-data

Returns the Isolation Forest anomaly detection report: flagged applicants, anomaly scores, and High Risk rate comparison. Powers the Anomalies dashboard.

GET/postman-collection.json

Downloads a ready-to-import Postman collection covering every endpoint above.
